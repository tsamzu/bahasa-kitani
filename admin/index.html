How review and publishing work
  1. Save and check your draft.
  2. Continue on GitHub and submit the prefilled issue.
  3. A maintainer checks it and adds dictionary-approved.
  4. The review workflow prepares a change and posts a pull-request link.
  5. Open that pull request, check the tests and merge it to publish.
